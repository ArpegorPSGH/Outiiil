# Importation armée pour attaque

## Objectifs
Gérer le cas où l'armée importée est non-compatible avec les troupes disponibles.

## Fonctionnement Détaillé
- Pour chaque type d'unité, mettre le minimum entre les troupes disponibles et la valeur importée
- Si au moins un type d'unité n'est pas suffisant pa rapport au nombre demandé en importation, afficher une notification
